# Automação Python - NEXUS

Este diretório foi criado conforme a arquitetura documentada para manter scripts Python isolados do núcleo Java.

Nesta primeira entrega, as regras centrais de estoque estão todas no backend Spring Boot. Futuramente, este módulo pode receber automações com PyAutoGUI para apoio a impressão, exportação ou rotinas operacionais assistidas.
